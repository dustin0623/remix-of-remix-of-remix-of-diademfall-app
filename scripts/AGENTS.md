# Scripts
- load-catalog.ts loads only the cards rows (stamped with game_version) from the TS catalog; game versions, pack editions, the chest reserve, rulesets, divisions and CE levels are SQL constant functions, not loaded rows; packs, banners, abilities, level stats and unlocks live only in TS and are not stored in the database (cards.set_id/banner_id are CHECK-guarded; Wayfarers have affiliation 'wayfarer' and a null banner_id; their old tables were removed). The loader retires older cards (inactive, never deleted) and never grants cards or changes ownership (why: one catalog definition; ownership comes from pack/chest openings; migrations stay DDL-only).
