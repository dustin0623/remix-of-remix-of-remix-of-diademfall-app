# Scripts
- load-catalog.ts loads catalog reference rows (game version, cards, catalog_hash, pack supply) from the TS catalog; rulesets, divisions and CE levels are SQL constant functions, not loaded rows; packs, banners, abilities, level stats and unlocks live only in TS and are not stored in the database (cards.set_id/banner_id are CHECK-guarded; Wayfarers have affiliation 'wayfarer' and a null banner_id; their old tables were removed). The loader retires older cards (inactive, never deleted) and grants new cards to existing players (why: one catalog definition; migrations stay DDL-only).
- load-catalog.ts also seeds legionnaire_reward_reserve once via seed_legionnaire_reserve(reserveComposition()) (a no-op after the first run) (why: the reward reserve comes from the TS config).
